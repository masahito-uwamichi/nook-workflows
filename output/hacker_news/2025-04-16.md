# Launch HN: mrge.io (YC X25) – Cursor for code review

**Score**: 169

mrge.ioは、AIを活用したコードレビュープラットフォームで、より少ないバグでより速くコードをマージできるよう支援する。PRのボトルネックを解消するために開発され、GitHubリポジトリを接続すると、AIが変更をレビューし、コードベース全体のコンテキストに基づいてコメントを残す。レビュー後、サンドボックスは破棄され、コードは削除される。

mrgeは、LinearのようなUIで、変更を論理的にグループ化し、重要な差分を強調表示することで、人間のレビューを効率化する。クラウドベースであるため、最新のAIモデルを実行でき、チーム全体で一貫したレビューが可能になる。デスクトップアプリも提供し、キーボードショートカットや高速なインターフェースを提供する。

今後は、コード量の増加に伴い、高レベルな変更を迅速に理解し、コードを抽象化するツールが重要になると考えている。mrgeは現在無料で利用でき、クローズドソースプロジェクトにはシート単位で課金する予定だが、オープンソースプロジェクトには引き続き無料で提供する。
